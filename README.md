# Credit Risk Model Validation

## Project Goal

This project investigates whether machine learning models can predict loan default risk using borrower and loan characteristics.

The project will compare multiple models and evaluate not only predictive performance, but also generalization, model behavior, and failure cases.

## Problem Type

- Supervised Learning
- Binary Classification
- Target: Loan Default

## Planned Approach

1. Explore and understand the dataset
2. Clean and preprocess the data
3. Split data into training, validation, and test sets
4. Establish a baseline model
5. Train Logistic Regression
6. Train and compare additional models
7. Evaluate accuracy, precision, recall, and confusion matrices
8. Validate model performance and generalization
9. Investigate false positives, false negatives, and other failure cases
10. Document conclusions and limitations

## Status

Project setup and dataset selection in progress.
